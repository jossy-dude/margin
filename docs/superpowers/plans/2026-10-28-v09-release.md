# v0.9 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v0.9.0 — one long pipeline of 15 gated workstreams covering import, semester archive, backup, self-update, onboarding, subject UX, cards, timer, notifications, sounds and widgets, followed by three end-of-pipeline review rounds and owner triage.

**Architecture:** Data shapes freeze first (WS1–WS4 incl. the release's single `user_version` migration), structure next (WS5–WS9), surfaces (WS10–WS14), native widgets last (WS15). Every workstream = one brief in `briefs/v09-*.md` + one subagent + one gate + one commit. UI workstreams delegate design to subagents running `impeccable`, `ui-ux-pro-max`, `design-taste-frontend`.

**Tech Stack:** Expo SDK 57 / React Native / TypeScript, Jest + dependency-cruiser (`npm run check`), Playwright browser asserts (`tools/*.mjs`, 412×915), SQLite (native) / MemoryRepository (web), expo-updates, expo-notifications, AndroidX Glance (widgets). New dependency: `expo-document-picker` only.

**Spec:** `docs/superpowers/specs/2026-10-28-v09-release-design.md` — the plan argues from the spec; executors read both.

**Execution method (owner-supplied):** subagent-driven — orchestrator dispatches one subagent per workstream with a brief, re-runs the gate itself; three review subagents (user-tester, senior-dev-auditor, adversarial vision) run once at the end, then owner triage.

## Global Constraints

- **R1** No +/− quantity steppers anywhere in v0.9: numeric keypad input (decimal keyboard), drag scrubber for ranges, typed fallback always.
- **R2** Import is merge-only (upsert by derived id, never deletes), preview counts + problems before commit, never throws (D11).
- **R3** Gate per workstream: `npm run check` green + workstream browser assert green + diff read → commit. One commit per workstream.
- **R4** Device-only claims labelled UNVERIFIED-ON-DEVICE and added to `docs/DEVICE_CHECKLIST.md`.
- **R5** Source-pin tests updated deliberately with rationale comments, never silenced.
- **No XLSX** (V3): import = JSON + CSV only.
- **One migration**: single `user_version` bump in WS2's window (semesters table + `subject_variants` + `variant_id`). No other migration in the release.
- **New dependencies:** `expo-document-picker` (WS1) — nothing else without owner approval.
- **The committed `android/` project ships, not `app.json`** — any config change lands in both, pinned by `src/test/native-config.test.ts`.
- **Web = in-memory repo**: e2e asserts run in one session; persistence claims native-only.
- **Version at release end:** `0.9.0`, versionCode bumped, `APP_VERSION` + `native-config.test.ts` updated together (§8 of spec).
- **Notifications customization nests inside the existing Settings → Reminders section** — no new section (owner, 2026-10-28).
- **Mascot** = pre-built pen character asset, free-for-commercial license recorded in repo (V7).
- **Exclusions (never in this release):** XLSX import, commute tracker, free-time system, desktop/tease UI, stats overhaul, sync/transport, full-screen alarm (D9), iOS-specific work, clock-face redesigns.

## Review Focus
