# Margin v0.5: implementation plan

**Spec:** `docs/superpowers/specs/2026-11-01-v05-release-design.md` · **Brief:** `docs/plan.md` · **Status:** approved 2026-11-01, with the O7–O9 changes (spec section 2)
**Supersedes:** `docs/superpowers/plans/2026-10-28-v09-release.md`

## How this runs
- **The orchestrator** (the main session) hands every task to a subagent through the Agent tool. Each subagent gets only the files, spec sections and skills it needs. The orchestrator runs the checkpoints, reads the diffs and commits.
- **Subagent types:**
  - `general-purpose` for implementation;
  - `Explore` for read-only reproduction or audits;
  - `impeccable:impeccable-finish-reviewer` for checking a design surface against its direction.
- **Every UI subagent loads `impeccable:impeccable` and `design-taste-frontend`.** It also gets the matching before photos from `docs/references/v0.3.1/`, as a starting point and never as the target. New captures go to `docs/references/v0.5/v0.5_*.jpg`.
- **Rules stated in every subagent prompt:**
  - no Claude attribution anywhere;
  - don't touch git config or `ios/`;
  - never run Gradle locally;
  - don't commit (the orchestrator commits);
  - run only the targeted tests;
  - a source-string test is replaced or updated with a rationale comment, never just turned green.
- **Sequencing:** tasks run in order unless they're marked **∥** (safe in parallel, with disjoint files, using `isolation: "worktree"` when they share no files with the running task).
- **Checkpoint (CP):**
  1. `npm run check` green (typecheck, lint with zero warnings, jest, depcruise);
  2. for UI work, the browser assertions (`tools/v05-*-assert.mjs`, Playwright at 412×915 and 320×690 against `http://localhost:8098`);
  3. the orchestrator reads the combined diff;
  4. commit.
  - A red checkpoint is fixed before anything new starts.
- **Native compile checkpoint (NCP):** a CP, then push `v2-improvements` and start a **build-only** run of the "Release APK" workflow (`workflow_dispatch`, `signing: debug`, with no tag and no release). It only runs if the owner has approved this plan (spec section 8).
