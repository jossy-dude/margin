# Margin v0.6 — plan

Owner's brief (2026-11-09, verbatim intent, numbered here):

| # | Owner asked | Why | Approach |
|---|---|---|---|
| 1 | Onboarding mascot is glitchy — check the real first-run on the phone | First impression | Wait until the phone is free (another agent uses it), clear app data, record the first run, fix what the frames show (Scrap rig / page swipes) |
| 2 | Performance is very bad, esp. first load after a phone restart | Cold start is the first thing anyone feels | Measure boot phases (timings in Diagnostics + logcat), then: load only the active look's fonts, show the shell before notification channels/audio are set up, defer non-visible work, keep pages lazy |
| 3 | Friends dislike the fonts and paper feel → a new theme via impeccable, "not too different but different" | Taste varies; keep collage for those who like it | A second **look** beside `collage`/`ink` with its own type and surfaces, chosen in Settings → Look and on onboarding's first page |
| 4 | Clocks are useless and hard to read → 3 readable watch faces, normal numerals, calm centre; delete the old nine | Legibility | Three new faces designed with impeccable; the nine and their gear/engraving engine go; stored face ids migrate to the nearest new face |
| 5 | Attendance status = **Present / Absent / Cancelled**, each with a reason | Real school cases | `AttStatus` becomes `p`/`a`/`c` + `why` code + free text. Present: on time, late entry, left early. Absent: late arrival (not let in), kicked out, sick, excused, skipped. Cancelled: teacher didn't come, holiday, moved, other — with a text line under it. Old codes migrate (l→p late, n→a late arrival, s→a sick, t→c teacher absent) |
| 6 | Foundation to connect tasks, time, events and notifications with Obsidian (v0.7) — read Bone vault | Bone plugin backlog: "Connect Margin and Obsidian in real time … Margin can send notifications for Obsidian tasks" | Bridge contract + data model now; transport (vault folder over Android storage access) in v0.7. See `docs/BRIDGE.md` |
| 7 | Redesign Stats' "Are you showing up?" and "Are you on top of your work?" with impeccable | Whole app improved | Redesign those two sheets; they read the new attendance model (#5) |
| 8 | Prepare the sync between Margin and the Bone plugins' DBs | Same as #6 | Stable ids, `updatedAt`, tombstones, an outbox/change log, and an import/export of the bridge envelope; the Bone side's half is written as a spec for the bone agent |

## Order (foundation first)
1. **A — attendance model (#5)**: domain, migration, sheet UI, analytics, import/export, tests.
2. **B — bridge foundation (#6, #8)**: schema (source/extId/updatedAt/deleted), change log, envelope codec, notifications for bridged tasks, `docs/BRIDGE.md`.
3. **C — cold-start performance (#2)**: boot timings first, then fixes; device-verified at the end.
4. **D — clocks (#4)**: three faces, old engine deleted.
5. **E — second look (#3)**.
6. **F — Stats redesign (#7)** on the new look and model.
7. **G — onboarding mascot on the phone (#1)** when the phone is free.
8. **H — release prep**: version 0.6.0 / versionCode bump, runtime version, DEVICE_CHECKLIST §V06, STATE.

Checkpoints: targeted jest while working; `npm run check` at the end of each lettered block, then commit.
Rules carried over: no attribution trailers, no local native builds, no push/tag/OTA without the owner.
