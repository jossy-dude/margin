## 2. Playback engine: SoundPool, not 14 media players

logcat at app start (pid 6412, 22:54:15–22:54:18) shows **16 `ExoPlayerImpl` + 16 `MediaSessionImpl` inits**, a 345 ms
lock contention on `AudioManager`, and `Skipped 47 frames`. `expo-audio` builds a full media player **and a media
session** per sound; v0.5 already hit Android's AudioTrack limit with more.

| Choice | Why |
|---|---|
| UI sounds through Android **`SoundPool`** in `modules/margin-native` (`Sfx.kt`, ~60 lines): load all short sounds once, `play(id, vol, rate)` | built for short UI sounds: one AudioTrack pool, ~5 ms latency, `rate` gives pitch variants for free (late/sick stamps, detent speeds) without extra files, no media sessions |
| `expo-audio` kept only for the Settings preview of longer clips and nothing at startup | |
| Alarm tones play in `AlarmService` (MediaPlayer, `USAGE_ALARM`), as today | the alarm must ring with the app closed |
| Lazy: the pool loads after first frame (`InteractionManager`) | cold start |

## 5. Build and audition

`scripts/sounds/build.mjs` replaces `scripts/fetch-sounds.mjs`:

| Step | What it does |
|---|---|
| `--fetch` | for each id in `scripts/sounds/picks.json` (the table above), asks the Openverse API for the record, re-checks the licence is CC0/BY, downloads the file to `assets/sounds-src/` (gitignored). On HTTP 403 (Freesound CDN, seen this session) it **does not retry or disguise itself**: it prints the Freesound page to download from by hand (a free Freesound account gives the original file) and the file name to save it as |
| `--build` | ffmpeg: trim (`atrim`), fade, rate/pitch when stated, `loudnorm` to the role's target, 48 kHz mono, WAV for UI / OGG for tones and notification sounds; writes `assets/sounds/`, `res/raw/` and `CREDITS.md` |
| `--measure` | `volumedetect` + `silencedetect` + duration for every output; fails a file with peak < −30 dB, leading silence > 30 ms (UI) or a clipped peak (0 dBFS) |
| `--audition` | regenerates **`output/sounds-audition/index.html`**: one row per role (what it is for, where it plays, the file, waveform image from `showwavespic`, duration, LUFS, licence, source link), a Play button, alternates side by side, and Keep / Swap buttons. Choices save in the page and **Export choices** downloads `choices.json`, which `--build --choices choices.json` applies |

The owner listens on the phone: `adb reverse tcp:8090 tcp:8090` + `npx serve output/sounds-audition -l 8090`, open
`http://localhost:8090` in the phone's browser, and judge with the phone speaker at the volume he uses. Alarm tones
are also auditioned through the in-app picker once the APK is built (the alarm stream sounds different).
