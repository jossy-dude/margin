# Reference photos: Margin v0.3.1, before v0.5

**These show the OLD app.** They are the "before" picture for the v0.5 redesign (`docs/plan.md`). Design from them; never copy them back as the target. If you are working on a version after v0.5, they are history, not the current design.

## How they were taken
- **Captured:** 2026-11-01, from the web build (`expo start --web`), in Chromium phone mode at 412×915, 2× pixel density, touch enabled. Saved as JPEG quality 90.
- **Build:** `APP_VERSION` 0.3.1 on branch `v2-improvements`, including the unreleased pre-v0.5 work: import doors, Semesters page, export-before-uninstall row.
- **Clock:** pinned to **Monday 2 Nov 2026, 10:20**, so Today shows a live class (Discrete Mathematics, 10:00–10:50). Countdowns in later shots tick on from there.
- **Data:** the built-in sample semester (the first-run demo set).
- **Theme:** "Follow phone" with the browser in light or dark mode. Every other setting is at its default: refined palette, dots paper, grain texture, warm pen, Rosette Blanc clock, Sight glass bar.

## What the web build can't show
- Notifications, widgets, haptics and sound.
- Exact native rendering of the paper grain and status bar.

Judge those from the code and from the owner's device test.
