## Session log — 2026-10-03 (V1 root-caused and fixed)
**V1 FAIL → fixed.** Phone (user's Android, Expo Go SDK 57, LAN `exp://10.111.172.130:8081`) showed a **red `[runtime not ready]` screen**: `expo-notifications: Android Push notifications … removed from Expo Go with the release of SDK 53`, stack top `warnOfExpoGoPushUsage ← addPushTokenListener`, all frames below it module-evaluation frames.

Root cause (not a warning — a hard `throw`, so the bundle never evaluated): `expo-notifications/build/index.js` re-exports `DevicePushTokenAutoRegistration.fx.js`, a **side-effect module** that calls `addPushTokenListener()` **at import time**, which calls `warnOfExpoGoPushUsage()`, which does `throw` when `isRunningInExpoGo() && Platform.OS === 'android'`. So merely importing the package root kills the app on Android in Expo Go SDK ≥53. Our code never touches push tokens — grep for `*PushToken*` in `src/` returns nothing; the app only schedules **local** notifications, which still work.

Fix: `src/services/notifApi.ts` re-exports the exact API `notifications.ts` uses from the **side-effect-free submodules** (`NotificationsHandler`, `NotificationPermissions`, `getAll…`/`schedule…`/`cancel…`, `setNotificationChannelAsync`, `NotificationsEmitter`, `Notifications.types`, `NotificationChannelManager.types`); `notifications.ts` now imports `* as N from './notifApi'`. Same native-module singletons, so a dev build behaves identically. **Do not "tidy" this back to `from 'expo-notifications'`** — that reintroduces the crash. `src/test/notifapi.test.ts` (3 tests) fails if the adapter ever resolves to the package root or loses an export.

Evidence: `npm run check` exit 0 (85/85 jest, up from 82); `npm run bundle` exit 0, 3.7 MB; fresh android dev bundle HTTP 200 (9.18 MB) contains `0` occurrences of the throw string and `0` of `DevicePushTokenAutoRegistration` / `getExpoPushTokenAsync` / `warnOfExpoGoPushUsage`, while still containing the 10 deep modules and the native module. Side finding: `AndroidImportance` is `UNKNOWN=0 … DEFAULT=5, HIGH=6` (not 3/4) — now pinned by a test.
